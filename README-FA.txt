Lilium Bank — نسخه آماده GitHub Pages و نصب در مرورگر

محتویات این ZIP را مستقیماً در ریشه (Root) مخزن GitHub قرار دهید؛
یعنی index.html، manifest.webmanifest، sw.js و دو آیکون باید کنار هم باشند.

مراحل انتشار و نصب:
۱) فایل‌های قبلی مخزن را با فایل‌های این بسته جایگزین کنید.
۲) در Settings > Pages، انتشار از شاخه main و پوشه /(root) را فعال کنید.
۳) نشانی HTTPS برنامه در GitHub Pages را با Chrome گوشی باز کنید.
۴) در منوی سه‌نقطه Chrome گزینه «نصب برنامه» یا «افزودن به صفحه اصلی» را بزنید.
۵) داخل برنامه به بخش «اعلان‌ها» بروید و «فعال‌سازی اعلان روی گوشی» را بزنید؛ سپس اجازه اعلان را صادر کنید.

یادآوری هفتگی:
پس از فعال‌سازی اعلان، زمان یادآوری هفتگی به‌صورت تصادفی تعیین می‌شود.
در مرورگرهایی که Periodic Background Sync را پشتیبانی می‌کنند، ممکن است اعلان در پس‌زمینه هم نمایش داده شود؛ زمان دقیق را خود مرورگر/سیستم‌عامل کنترل می‌کند.
در مرورگرهای فاقد این قابلیت، اعلان پس از رسیدن زمان تصادفی، در اولین باری که برنامه باز باشد نمایش داده می‌شود؛ بنابراین نمایش هفتگی هنگام بسته بودن کامل برنامه در همه گوشی‌ها تضمین‌شدنی نیست.

نکته مهم: قبل از جایگزینی نسخه قبلی، از اطلاعات برنامه پشتیبان بگیرید. نصب PWA فقط از HTTPS (مانند GitHub Pages) یا localhost ممکن است.
