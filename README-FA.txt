Lilium Bank — بسته کامل PWA برای GitHub Pages و نصب روی گوشی

این ZIP را استخراج کنید و تمام محتویات آن را مستقیماً در ریشه مخزن GitHub قرار دهید؛ فایل‌ها نباید داخل یک پوشه تو در تو باشند.

انتشار و نصب در Android:
۱) در GitHub وارد مخزن شوید و فایل‌های قبلی را با محتویات این بسته جایگزین کنید.
۲) در Settings > Pages، انتشار از شاخه main و پوشه /(root) را انتخاب کنید.
۳) پس از فعال شدن GitHub Pages، نشانی HTTPS سایت را با Chrome گوشی باز کنید.
۴) از منوی سه‌نقطه Chrome گزینه «نصب برنامه» یا «افزودن به صفحه اصلی» را انتخاب کنید. اگر «نصب برنامه» نمایش داده نشد، صفحه را یک‌بار تازه‌سازی کنید و مطمئن شوید manifest و sw.js در همان مسیر index.html منتشر شده‌اند.
۵) برای اعلان‌ها، داخل برنامه بخش اعلان‌ها را باز و اجازه اعلان را صادر کنید.

محتویات اصلی: index.html، manifest.webmanifest، sw.js، icon-192.png، icon-512.png و .nojekyll.

یادآوری هفتگی: زمان‌بندی تصادفی در کد برنامه وجود دارد، اما اجرای اعلان در پس‌زمینه به پشتیبانی مرورگر/سیستم‌عامل وابسته است و در همه گوشی‌ها تضمین نمی‌شود.

نکته: ZIP را مستقیماً نصب نکنید؛ ابتدا آن را در ریشه مخزن GitHub Pages منتشر کنید و سپس برنامه را از نشانی HTTPS نصب کنید. قبل از جایگزینی نسخه قبلی، از اطلاعات برنامه پشتیبان بگیرید.
