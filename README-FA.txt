Lilium Bank — بسته آماده انتشار و نصب به‌صورت PWA

فایل‌های این بسته را مستقیماً در ریشه (Root) مخزن GitHub قرار دهید؛
یعنی index.html، manifest.webmanifest، sw.js و دو فایل آیکون باید کنار هم باشند.
برای آیکون‌ها پوشه جداگانه‌ای وجود ندارد.

۱) فایل‌های قبلی مخزن را با فایل‌های این بسته جایگزین کنید.
۲) در Settings > Pages، انتشار از شاخه main و پوشه /(root) فعال باشد.
۳) پس از انتشار، نشانی HTTPS برنامه را با مرورگر گوشی باز کنید.
۴) در Chrome از منوی سه‌نقطه گزینه «نصب برنامه» یا «افزودن به صفحه اصلی» را بزنید.

نکته: نصب PWA فقط از نشانی HTTPS (مانند GitHub Pages) امکان‌پذیر است.
