# Lilium Bank — نسخه قابل نصب موبایل (PWA)

این پوشه نسخه آماده انتشار برنامه در GitHub Pages است. فایل اصلی برنامه حفظ شده و فقط قابلیت‌های نصب‌پذیری، آفلاین و نمایش اعلان به آن اضافه شده است.

## انتشار روی GitHub Pages
1. وارد GitHub شوید و یک مخزن جدید بسازید؛ مثلاً `lilium-bank`.
2. همه فایل‌ها و پوشه‌های همین پروژه را در ریشه مخزن آپلود کنید؛ ساختار `index.html`، `manifest.webmanifest`، `sw.js` و پوشه `icons` باید حفظ شود.
3. در مخزن به **Settings → Pages** بروید.
4. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
5. شاخه `main` و پوشه `/(root)` را انتخاب و Save کنید.
6. پس از انتشار، آدرس GitHub Pages را با Chrome روی گوشی باز کنید.

## نصب روی اندروید
1. سایت را با Chrome و از آدرس HTTPS باز کنید.
2. از منوی سه‌نقطه Chrome گزینه **Install app / نصب برنامه** یا **Add to Home screen / افزودن به صفحه اصلی** را بزنید.
3. نام Lilium Bank و آیکن تصویری برنامه نمایش داده می‌شود؛ سپس نصب را تأیید کنید.

## اعلان‌ها
- داخل برنامه، بخش «اعلان‌ها» را باز کنید و «فعال‌سازی اعلان روی گوشی» را بزنید؛ اجازه اعلان را در پنجره Android/Chrome تأیید کنید.
- اعلان سررسید اقساط فعلی برنامه هنگام باز بودن برنامه یا وقتی دوباره به آن برمی‌گردید بررسی می‌شود.
- Service Worker امکان نمایش اعلان Push دریافتی از سرور را هم آماده کرده است؛ اما برای ارسال اعلان واقعی در زمانی که برنامه کاملاً بسته است، هنوز باید سرویس Push و کلیدهای VAPID و ثبت اشتراک Push روی یک بک‌اند راه‌اندازی شود. GitHub Pages به‌تنهایی سرور ارسال اعلان یا زمان‌بندی پس‌زمینه نیست.

## نکته مهم درباره اطلاعات مالی
اطلاعات فعلی برنامه در `localStorage` مرورگر ذخیره می‌شود. انتقال از فایل HTML قبلی (`file://`) به آدرس GitHub Pages به معنی انتقال خودکار اطلاعات قبلی نیست؛ همچنین اطلاعات هر مرورگر/دامنه جداست. قبل از کنار گذاشتن نسخه قبلی، اطلاعات مهم را از داخل امکانات خود برنامه نگه دارید یا منتقل کنید. پاک‌کردن داده‌های مرورگر می‌تواند اطلاعات محلی را حذف کند.

## آفلاین
پس از اولین بار باز کردن موفق برنامه با اینترنت، پوسته برنامه در حافظه کش ذخیره می‌شود و بخش اصلی برنامه برای بازدیدهای بعدی آفلاین در دسترس خواهد بود. برای دریافت نسخه جدید پس از به‌روزرسانی، یک بار برنامه را با اینترنت باز کنید.
